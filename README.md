## ✨ Features
- 🎬 **Cinematic Royal Opening Curtain**: Interactive royal wax seal envelope with Sanskrit invocation *“॥ श्री गणेशाय नमः ॥”* and 3D curtain parting.
- 🎵 **Festive Soundtrack**: Plays *“Rote Gachey Khobor (Sarva Mangala)”* by Rupak Tiary with floating gold audio equalizer and mute/unmute controls.
- 🪷 **Canvas Rose Petal Shower**: Physics-based HTML5 canvas particle shower with falling petals and golden bokeh sparkles.
- ⏳ **Live Countdown**: Real-time ticker counting down to November 25, 2026.
- 📜 **Wall of Blessings (Shubh Sandesh)**: Warm, sacred messages from both sets of parents and all 4 family branches.
- 📱 **Multi-Device Vision**: Mobile-optimized for WhatsApp sharing, tablets, and 4K Smart TVs.

## 🛠️ Tech Stack
- **Framework**: React 19 + TypeScript
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React
- **Effects**: Canvas Confetti & HTML5 Canvas Particles
- **Bundler**: Vite

## 🚀 Getting Started

### Local Development:
```bash
npm install
npm run dev
```

### Production Build:
```bash
npm run build
npm run preview
```
The compiled, deployment-ready files are in the `dist/` directory.
